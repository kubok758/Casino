# Aurum Casino

Демо-казино с тремя игровыми автоматами на общем балансе виртуальных кредитов.
Без сборки и зависимостей: чистые HTML, CSS и JavaScript.

| Автомат | Что это | Линии | RTP | Выигрыш |
|---|---|---|---|---|
| **Lucky 7** | механический однорукий бандит 1960-х с рычагом | 1 | 96,28 % | 1 из 5,5 |
| **Cosmic Fortune** | видеослот 5×3 с дикими символами и бесплатными вращениями ×2 | 10 | 95,58 % | 1 из 3,8 |
| **Crown Jewels** | ступенчатые барабаны 3×3, корона заменяет любой камень | 5 | 96,42 % | 1 из 3,3 |

## Запуск

Откройте `index.html` в браузере. Или поднимите локальный сервер:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Что внутри

- **Барабаны** рисуются на canvas. У механических автоматов — честная проекция цилиндра
  (символы сжимаются к краям окна), смаз при вращении, отскок при остановке, «интрига»
  на последнем барабане, когда до крупного выигрыша не хватает одного символа.
- **Символы** нарисованы кодом: фрукты, колокол, BAR, семёрка, огранённые камни,
  планеты, ракета, галактика, неоновые буквы. Внешних картинок нет.
- **Звук** синтезируется через Web Audio: треск механизма, щелчки рычага, звонок
  электромеханического автомата, звон монет, фанфары.
- **Рычаг** Lucky 7 можно тянуть мышью или пальцем.
- **Управление**: «Крутить», пробел, рычаг; повторное нажатие во время вращения
  останавливает барабаны. Есть автоигра и максимальная ставка.
- Баланс сохраняется в `localStorage`; когда кредиты заканчиваются, демо-счёт можно пополнить.

## Математика

Ленты барабанов, линии и таблицы выплат лежат в `js/engine.js`. Результат вращения
выбирается криптографическим генератором (`crypto.getRandomValues`). У Lucky 7 — 22
физические остановки и «виртуальный барабан» на 64 позиции, как в настоящих автоматах.

RTP считается полным перебором всех комбинаций остановок:

```bash
node tools/rtp.js            # точный расчёт
node tools/rtp.js --sim 1e6  # плюс проверка симуляцией
```

## Структура

```
index.html        разметка зала и трёх кабинетов
css/styles.css    оформление
js/engine.js      ленты, линии, выплаты, генератор случайных чисел
js/symbols.js     отрисовка символов
js/reels.js       рендер и физика барабанов
js/audio.js       синтез звука
js/fx.js          монеты при выигрыше
js/machine.js     логика автомата: ставки, вращение, бонус, рычаг
js/app.js         баланс, таблицы выплат, запуск
tools/rtp.js      расчёт RTP
```

Проект демонстрационный: только виртуальные кредиты, без денежных ставок и выплат. 18+
